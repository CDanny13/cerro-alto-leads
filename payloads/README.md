# Payloads de ejemplo

Diez eventos tal como los envía el conector de leads, en el orden en que llegarían. El formato está en la sección "Conector de leads" de la página de la prueba.

Para mandarlos a tu webhook:

```bash
python3 enviar_payloads.py https://tu-sistema.example.com/webhook
```

Revisa cada uno con calma antes de construir: no todos son lo que parecen.
